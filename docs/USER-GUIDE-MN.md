# RAINY PDF — Суулгаж ашиглах заавар

## Суулгах
GitHub Releases-ээс `RainyPDF-0.1.0-Setup.exe` татаж нээнэ. Суулгац PDF, OCR, Office хөдөлгүүрүүдийг хамтад нь суулгана. Desktop эсвэл Start цэснээс цэнхэр R тэмдэгтэй RAINY PDF нээнэ. Анхны хувилбар unsigned тул нийтлэгчийн дижитал гарын үсэг хараахан байхгүй.

## PDF засах
1. `PDF файл нээх` дарж эсвэл PDF-ээ цонх руу чирж оруулна.
2. Баруун талын хэрэгслээс `Текст нэмэх` сонгоно. Текстээ бичиж, хэмжээ/өнгө тохируулаад хуудсан дээр хүрээ татна.
3. `Текст солих` нь сонгож болох энгийн текстийн хэсгийг жинхэнэ арилгаж орлуулна. Багтахгүй бол үйлдэл цуцлагдана. Scan дээр OCR хэрэглэнэ.
4. `Зураг оруулах` / `Зурган гарын үсэг` сонгоод байрлалын хүрээ татаж PNG/JPG зургаа сонгоно.
5. `Засвар → Нэмсэн объект зөөх / устгах` ашиглаж өөрийн оруулсан объектуудыг удирдана.
6. Ctrl+Z буцаах; Ctrl+Y дахин хийх. Ctrl+Shift+S шинэ хуулбар хадгалах.

## Мэдээлэл нууцлах
`Мэдээлэл арилгах` сонгоод хүрээ татна. Баталгаажуулсны дараа тухайн хүрээний агуулга экспортолсон файлаас жинхэнэ арилна. Metadata, хавсралт, bookmark мөн цэвэрлэгдэнэ. Шинэ файлаа нээж, хайлт/хуулах болон дүрслэлээр нягтална. Өөр хуудсан дээр давтагдсан мэдээллийг тусад нь сонгож арилгана.

## Хуудас цэгцлэх
Зүүн жагсаалтаас хуудсаа сонгоод эргүүлэх/устгах/хуулбарлах товч хэрэглэнэ. `Хуудасны дараалал` дээр 3,1,2 гэх мэт хуудсаа нэг бүрчлэн бичнэ. `Файл` цэснээс нэгтгэх, хуудас салгах, шахах үйлдэл сонгоно.

## OCR
- `Хөрвүүлэх → OCR · Хайдаг PDF`: Монгол/Англи хэлээ сонгож searchable PDF гаргана.
- `Хөрвүүлэх → OCR · Текст таних / засах`: таньсан текстээ эх зурагтай харьцуулж засаад TXT/DOCX хадгална. Засвар нь эх скан зургийн үсгийг өөрчлөхгүй.
- Тод, шулуун, гэрэлтүүлэг жигд 200–300 DPI хэвлэмэл скан ашиглавал илүү тохиромжтой. Тоо, регистр, нэрийг заавал хянана.

## Word / Excel
- PDF → Word: `Хөрвүүлэх` цэснээс native layout эсвэл scan OCR text горимоо сонгоно.
- PDF → Excel: хүснэгтийн preview дээр нүднүүдээ хянаж засна. Текстэн хүснэгт олдоогүй бол одоогийн хуудсанд OCR хүснэгт таних санал гарна. Энгийн хүрээтэй скан хэрэглэнэ.
- Word / Excel → PDF: DOC/DOCX/XLS/XLSX файл сонгоно. Програмтай хамт суусан LibreOffice ашиглана; Microsoft Office тусдаа шаардахгүй. Фонт, хүснэгтийн байршил өөрчлөгдөж болох тул PDF-ээ нягтална.

## Хэвлэх
Ctrl+P → `Хуудаст багтаах` эсвэл `Бодит хэмжээ · 100%` → Preview. Хэвлэх цонхноос хэвлэгч, чиглэл, хуулбар/хуудасны сонголтоо шалгаад Print дарна. 100% үед хэвлэгчийн хэвлэх боломжгүй захад агуулга тасарч болох тул preview-г хянана.
`Үнэмлэх / Цээж зураг` нь A4 PDF layout гаргана. Үнэмлэхийн хоёр талын зураг эсвэл цээж зургийн хэмжээг сонгоод PDF-ээ нээж хэвлэнэ. Цээж зургийг албан ёсны биометрийн шаардлагад автоматаар баталгаажуулахгүй.

## Алдаа ба нууцлал
Диск дүүрсэн, буруу нууц үг, гэмтсэн файл, текст хүрээнд багтахгүй үед тайлбар харагдана. Урт боловсруулалтыг `Цуцлах` дарж зогсооно. Хадгалаагүй өөрчлөлттэй цонх хаахад баталгаажуулна. Сүүлийн файлын нэрсийг `Засвар → Сүүлийн файл жагсаалт арилгах` ашиглаж цэвэрлэнэ.
